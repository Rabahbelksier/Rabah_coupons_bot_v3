---
name: Meta attribution design
description: User-approved distinction between fixed campaign source and per-visit Telegram attribution.
---

Use a unique short visit token in the Telegram start link generated by the redirect page, while keeping the campaign source fixed in environment configuration. Store the campaign source, not the visit token, as the user's source attribution. Also support direct Telegram links carrying the configured fixed source, without inventing browser-visit data.

**Why:** The user explicitly selected “رمز زيارة ومصدر ثابت” after discussing why a shared source cannot identify an individual browser visit.

**How to apply:** Preserve this distinction when planning or implementing Meta-to-Telegram attribution. Count only the first eligible use of the bot; existing users and repeated starts must not become new campaign subscriptions. Do not change existing bot posts or messages as part of this work.
